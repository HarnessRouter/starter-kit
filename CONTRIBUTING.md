# Contributing

Thanks for helping improve HarnessRouter starter demos and kits.

1. Fork the repository and create a focused branch.
2. Keep HarnessRouter credentials in your local `.env` file only.
3. Run `npm test` and `npm run build` before opening a pull request.
4. Explain the user-facing behavior and security impact of your change.

Please keep pull requests small and avoid committing generated runtime data from `demos/*/data/`.
